## 1. INTRODUCTION

The Fake News Detector Application is a machine learning-based solution designed to detect and classify news as either FAKE or REAL. It is built using Python, Flask, and machine learning techniques. This system provides users with an easy-to-use interface to validate the authenticity of news articles.

---

## 2. SYSTEM REQUIREMENTS

- Operating System: Linux / Windows / MacOS
- Python 3.x installed
- Flask Framework
- Libraries: Pandas, NumPy, Sklearn, Joblib, Flask

---

## 3. INSTALLATION GUIDE

1. Clone the project repository:

```
git clone <repository_link>
```

2. Navigate to the project folder:

```
cd FakeNewsDetector
```

3. Create a virtual environment:

```
python -m venv fake-news-env
```

4. Activate the environment:

```
source fake-news-env/bin/activate
```

5. Install dependencies:

```
pip install -r requirements.txt
```

6. Train the model:

```
python train_model.py
```

7. Run the application:

```
python app.py
```

---

## 4. HOW TO USE THE SYSTEM

- Open your browser and go to:

```
http://127.0.0.1:5000/
```

- Enter any news text in the provided form.
- Click the "Check" button.
- The system will display the result as FAKE or REAL.
